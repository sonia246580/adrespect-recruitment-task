# adRespect Recruitment Task

Responsive landing page created as part of the recruitment process for **adRespect.pl**.

## 🌐 Live Demo

https://adrespect-recruitment-task-rgqjyrj1v-sonia22.vercel.app

## 📂 Repository

https://github.com/sonia246580/adrespect-recruitment-task

## 📖 About the Project

The goal of this project was to recreate the provided graphic design as a fully responsive website using Vue 3.

The implementation includes:

- Responsive layout for desktop, tablet and mobile devices
- Mobile navigation drawer
- Hero section
- Services section
- About section
- Masonry projects gallery
- Image popup gallery
- Expandable projects section
- Instagram section
- Footer
- Smooth scrolling navigation

## 🛠️ Technologies

- Vue 3
- Vite
- JavaScript
- Tailwind CSS

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sonia246580/adrespect-recruitment-task.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the production version:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
